# Gaming Tournament Manager — Arena

**Arena** is a desktop-based Gaming Tournament Management System developed using Java Swing and SQLite. The application provides a centralized platform for managing gaming tournaments, players, and tournament hosts through an interactive graphical user interface.

The system includes a **user authentication module** with registration and sign-in functionality, allowing users to access the management dashboard after successful login. It supports CRUD (Create, Read, Update, and Delete) operations for tournaments, players, and hosts, enabling users to maintain records efficiently.

The application follows an object-oriented design using classes, inheritance, encapsulation, and Data Access Objects (DAO) to separate business entities from database operations. JDBC is used to connect the Java application to the SQLite database, ensuring persistent storage of tournament and user information.

### Key Features
- User registration and sign-in.
- Tournament management, including titles, games, event dates, and prize pools.
- Player management, including names, email addresses, and gaming IDs.
- Host management, including organization and contact details.
- SQLite database integration using JDBC.
- Dark-themed graphical user interface built with Java Swing.
- Object-oriented architecture with separate model, DAO, database, UI, and exception packages.

### Technologies Used
**Java, Java Swing, JDBC, SQLite, Object-Oriented Programming (OOP)**

### Objective
The primary objective of Arena is to simplify gaming tournament administration by providing an organized, user-friendly desktop application that demonstrates object-oriented programming principles, database connectivity, exception handling, and CRUD operations in Java.
